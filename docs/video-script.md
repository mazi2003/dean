## Ключевые акценты для жюри (Что проговорить и показать обязательно)
- **Изоляция данных (IDOR-защита):** Явное переключение `Айгуль (ДУ-101)` → `Тимур (ДУ-205)` → `Деканат` доказывает разделение маршрутов, ролей и персональных сведений на реальном бэкенде.
- **Сквозной цикл услуги (End-to-End):** Заявка подана студентом → обработана инспектором деканата → уведомление доставлено студенту → демонстрационный макет PDF открыт.
- **Антифрод и UX-детали:** Полноэкранный СКУД QR-сканер с TOTP и живыми часами, экспорт `.ICS`, светлая/тёмная темы, RU/EN, 360px mobile-first.
- **Юридическая чистота конкурса:** Отсутствие реальных брендов вузов, наличие обязательного дисклеймера в футере на всех экранах.
