# Цифровой деканат будущего (Digital Dean's Office of the Future)
> **Конкурсный концепт личного кабинета студента • DemoTech University**  
> *Не является официальным сервисом университета. Все данные, оценки, фамилии и номера документов вымышлены.*

---

## 🚀 О проекте

«Цифровой деканат будущего» — это веб-сервис и PWA-приложение, объединяющее все аспекты студенческой жизни в одном месте:
- **Умный главный экран «Сегодня»**: отсчет времени до следующей пары, номер аудитории, уведомления о заменах и статус заказанных документов.
- **Расписание с оперативными изменениями**: день/неделя, бейджи замен аудиторий и переносов, экспорт в `.ics` (Google/Apple Calendar).
- **Успеваемость и зачетка**: средний балл GPA, шкала БРС (0-100), кольцо закрытых кредитов ECTS, график сессии и предупреждения о задолженностях/пересдачах.
- **Справки и электронные заявления**: оформление в 3 клика, отслеживание жизненного цикла заявки, скачивание юридически значимого PDF с квалифицированной ЭЦП деканата и QR-кодом проверки подлинности.
- **Цифровой студенческий билет (Digital Student ID)**: защищенная карточка с голограммой, динамическим QR-кодом и интерактивной симуляцией NFC-прохода через турникеты кампуса.
- **AI Academic Copilot**: контекстный помощник деканата, отвечающий на вопросы по учебе с соблюдением строгой приватности.
- **Панель сотрудника деканата**: интерфейс инспектора для согласования заявлений с выпуском ЭЦП, просмотра реестра академических групп и личных дел студентов, управления расписанием и экзаменационной сессией, а также публикации объявлений.

## 🛠️ Технологический стек

- **Frontend**: React 19, Vite 8, TypeScript, Tailwind CSS v4, Lucide React, QRCode, PWA + Service Worker.
- **Backend**: Node.js 20, Fastify v5, Zod v4, Argon2, JSON Web Tokens (`@fastify/jwt`), Helmet, CORS, Rate Limiting.
- **Database**: PostgreSQL 16, Prisma ORM v6.19.
- **QA и безопасность**: Vitest, Testing Library, Supertest, Playwright (1280×800 и 360×740), `@axe-core/playwright`, oxlint, Docker + Caddy.
- **Безопасность**: Защита от IDOR (каждый запрос привязан к сессии `userId`), пароли в Argon2id (память 64МБ, 3 итерации), httpOnly + Secure + SameSite=Lax cookies, fail-closed секреты в продакшене, Rate Limiting, Helmet.

## 💻 Быстрый запуск

### Вариант 1: Запуск фронтенда (со встроенным автономным API-движком)
Фронтенд спроектирован так, чтобы работать автономно с сохранением состояния в `localStorage` (полная эмуляция OpenAPI-контракта). Это позволяет запускать прототип на любом компьютере или статическом хостинге без необходимости предварительно настраивать базу данных:

```bash
cd frontend
npm install
npm run dev
```
Откройте в браузере: `http://localhost:5173`

Для сборки продакшн-бандла:
```bash
npm run build
npm run preview
```

### Вариант 2: Запуск полного стека через Docker Compose
```bash
cp .env.example .env
docker compose up -d
```
Сервисы поднимутся за Caddy reverse proxy:
- Веб-приложение: `http://localhost`
- Fastify API: `http://localhost/api/v1`
- PostgreSQL: порт 5432

---

### Вариант 3: Автотесты и контроль качества
```bash
# Backend (unit + security/IDOR/RBAC integration + v8 coverage)
cd backend && npm run typecheck && npm run build && npm run test:coverage

# Frontend (oxlint + Vitest + production bundle)
cd frontend && npm run lint && npm test && npm run build

# E2E Desktop (1280x800) + Mobile (360x740) + WCAG Axe + Load benchmark (100 VU; предварительно соберите frontend)
cd e2e && npm run test:e2e && npm run test:load
```
